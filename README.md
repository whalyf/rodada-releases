# Rodada — instaladores

Este repositório hospeda apenas os **instaladores do Rodada** (PDV de comandas), para que o aplicativo já instalado
encontre e baixe as atualizações automaticamente.

O código-fonte do Rodada **não** é público e este repositório não o contém. Todos os direitos reservados.

Se você é cliente e precisa de ajuda, fale com quem forneceu o Rodada.
